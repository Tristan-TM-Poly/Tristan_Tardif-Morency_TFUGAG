Fact

Ce que le benchmark sait

Les endpoints et résultats décrits dans les sources officielles citées; les rôles failure/near-miss/control; les dimensions explicitement appariées ou non.

Inference

Ce qu'il teste ensuite

Si des représentations simples ou Tristan discriminent les outcomes au-delà de baselines document/timeline et attribute-table.

Unknown

Ce qui reste inconnu

Généralisation hors échantillon, causalité des mécanismes, calibration de l'entropie institutionnelle et transfert inter-secteurs.

Ce qui falsifierait l'intérêt de la couche Tristan : si les features d'entropie, HGFM ou CVCD ne battent pas des baselines simples sur des holdouts gelés, elles doivent être réduites, redéfinies ou supprimées.

Sources & reproductibilité

Le code canonique du benchmark est public dans TTM-TFUGA-AI7-TRISTAN2. La page est une projection de ce corpus, pas une source primaire.

USIF ne classe pas les entreprises ou personnes par « culpabilité ». Le benchmark est centré sur des processus, endpoints, contrôles et mécanismes documentés.

USIF-Bench · Generated ≠ Verified · Structural contrast ≠ causal match ≠ predictive validation.
