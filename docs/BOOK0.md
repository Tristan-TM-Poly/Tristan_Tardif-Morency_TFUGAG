# Foundational BOOK0 — Tristan_Tardif-Morency_TFUGAG

**Status:** R0.1 local foundational kernel  
**Role:** clean public gateway into the generalized TFUGA research architecture

## 1. Mission

This repository should expose a comprehensible, reproducible and bounded public
entrypoint into the TFUGA architecture.

Its local BOOK0 is not the complete research archive. It is the smallest public
foundation needed to navigate stable concepts, crystallizable branches,
computational examples, publication routes and verification status.

## 2. Inheritance

Shared governance and reusable primitives are inherited from BOOK0 Ω in
`Tristan-TM-Poly/TTM-TFUGA-AI7-TRISTAN2`.

```text
PublicGateway != CompletePrivateCorpus
SharedCanon > duplicated explanation
StrongClaim → explicit validation path
ALL scope != ALL mutation
```

Projection paths use the public opaque `P1..P16` ABI. Their private semantic
sidecar is not reproduced in this repository.

## 3. Local structure

The target public surface separates:

- stable minimal canon;
- crystallizable branches;
- exploratory branches;
- reproducible calculations/simulations;
- publication-ready artifacts;
- audit/promotion history.

A reader should be able to tell which layer an object belongs to without reading
the whole repository.

## 4. Formalization contract

A promoted object should expose as applicable:

```text
name
+ definition
+ assumptions
+ equations/contracts
+ examples
+ tests/proof route
+ limits
+ status
+ upstream/downstream links
```

A strong verbal formulation that lacks these elements remains exploratory.

## 5. BOOK0_MIN

For subject `x`:

```text
BOOK0_MIN(x)
= root inherited contracts
+ local definition/dependency cone
+ minimum verification surface
```

The public gateway should favor progressive disclosure rather than forcing the
entire theory forest into every explanation.

## 6. Reproducibility

Computational claims should have minimal examples and tests where appropriate.
Mathematical claims should distinguish definitions, conjectures, propositions,
proof sketches and completed proofs.

Publication formatting is not a substitute for verification.

## 7. Relationship to the BOOK0 hypergraph

The local BOOK0 is connected to BOOK0 Ω through `INHERITS` and to repository
objects through typed `CONTAINS`, `DEPENDS_ON`, `IMPLEMENTS`, `TESTS` and
`EVIDENCES` relations where declared.

Opaque projection paths may generate public views without disclosing private
projection semantics.

## 8. OAK boundary

Public clarity requires visible boundaries among:

- intuition;
- definition;
- exploratory model;
- local demonstration;
- theorem/proof;
- experimental evidence;
- canonical reusable contract.

No public-facing simplification may silently upgrade epistemic status.
